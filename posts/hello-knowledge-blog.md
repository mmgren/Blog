这是知识笔记的第一篇。目标很简单：**写作时只用 Markdown，阅读时不必绑在一个 App 里。**

## 你只需要记住一件事

正式内容都放在仓库根目录的 `posts/` 目录。每一篇 `.md` 或 `.mdx` 文件都会变成网站上的一篇文章，同时也能在 GitHub 上直接打开阅读。

这样做的好处是：

- 写的时候像记笔记，不需要登录后台。
- 同一份文件可以发布到网页。
- 源文件可以给别人看、做 code review，也可以自己用 Obsidian 打开。
- RSS 订阅者能在自己习惯的阅读器里收到更新。

## 阅读入口

| 入口 | 适合做什么 |
| --- | --- |
| 网站 | 手机或电脑浏览，有目录、标签、搜索和深色模式 |
| GitHub | 看 Markdown 原文、提 issue、分享仓库链接 |
| RSS | 把更新接到任何 RSS 阅读器 |
| 本地编辑器 | 离线写作和查阅 |
